LO MARCADO EN TU TEMARIO

Los conceptos clave

Piensa en cada tema como una herramienta para resolver una parte del diseño web.

01 · HTML

Elementos semánticos

Son etiquetas que describen el contenido. Por ejemplo, <nav> es para la navegación y <main> para el contenido principal.

<main>Contenido principal</main>
02 · CSS

Sintaxis y formas de uso

Una regla tiene un selector y declaraciones. El CSS puede ir en línea, dentro de <style> o en un archivo externo.

.titulo { color: coral; }
03 · CSS

Orden y herencia

Indentar hace el código más fácil de leer. Los comentarios dejan notas. Algunas propiedades, como el color, pueden heredarse de un elemento padre.

/* Esto es un comentario */
04 · CSS

Especificidad

Si varias reglas afectan al mismo elemento, el navegador decide cuál tiene prioridad. En general, un ID pesa más que una clase, y una clase más que una etiqueta.

#aviso > .aviso > p
05 · CSS

Flexbox, Grid y breakpoints

Flexbox organiza elementos en una dirección. Grid usa filas y columnas. Los breakpoints son anchos donde el diseño cambia para ajustarse a la pantalla.

display: grid;
06 · CSS

Media queries

Permiten aplicar estilos solo cuando se cumple una condición, por ejemplo, cuando la pantalla es estrecha.

@media (max-width: 600px)
07 · CSS

Pseudo-elementos y clases

Los pseudo-elementos añaden detalles visuales. Las pseudo-clases describen estados como pasar el cursor sobre un botón.

::before   :hover
08 · CSS

z-index

Indica qué elemento aparece delante cuando varios se superponen. Funciona como el orden de capas de una pila.

z-index: 2;
